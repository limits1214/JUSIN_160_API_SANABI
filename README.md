## 주요 콘텐츠

- 마우스 조준 → 갈고리 발사 → 지형 결속 → 진자 스윙·당겨 이동으로 이어지는 사슬팔 액션
- 이동·점프·대시·벽 등반·천장 이동과 갈고리 포획·처형을 결합한 플레이어 전투
- Trooper·Defender·Warrior·Survey Drone 등 적별 탐지·추적·공격 패턴
- 폭격·기관총·몸통 박치기·집속탄으로 구성된 화조 보스전과 부위별 파괴 연출
- 챕터 선택 → 튜토리얼 → 전투 스테이지 → 보스전 → 엔딩으로 이어지는 게임 흐름

## 구현 내용

### 핵심 시스템

- GameObject·Scene·Manager 생명주기와 부모-자식 오브젝트 계층·렌더 순서 관리
- 입력·시간·스크롤·사각형/라인 충돌과 GDI 더블 버퍼링·스프라이트 애니메이션
- FMOD 채널 기반 BGM/SFX 재생과 비트맵·게임 진행 상태 관리

### 콘텐츠 구현

- 갈고리 길이·각도 기반 진자 운동, 관성 점프, 벽·천장 이동과 8방향 탈출 대시
- 갈고리 처형을 일반 적 전투와 부유 폭탄을 활용한 보스 공략 기믹으로 확장
- 적 웨이브·챕터 해금·게이트 전환과 4종 공격 패턴의 화조 보스전 구현

### Tool

- 타일·라인·사각형·피해 충돌체와 게임 오브젝트를 배치하는 자체 GDI 편집 도구
- 맵 데이터 바이너리 Save/Load와 오브젝트·씬·BMP·스크롤 런타임 디버그 패널
